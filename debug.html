怎么自己验证

  • 回到 首页 连续快速滚动，观察 FPS 是否稳定贴近屏幕刷新率
  • 打开 DevTools 的 Performance 面板录制滚动，Layout / Paint 应极少出现，动画只走 Composite
  • 在搜索框快速连打一串字符，防抖会把十几次输入压成一次查询
  • 切换深浅主题、缩放窗口到手机宽度，检查是否出现布局跳动
  • 打开 Rendering → Layout Shift Regions，滚动时不应出现高亮区域
凭感觉优化必然翻车：先测量（LCP / INP / CLS + Long Task），再动手。

样品已落实的工程点

  • 零框架、零外部请求，资源全部本地：消除运行时水合与网络抖动
  • 系统字体栈：字体下载 0 字节；固定宽高比封面：CLS ≈ 0
  • content-visibility: auto + contain-intrinsic-size：屏外卡片跳过渲染
  • 动画仅 transform / opacity；滚动监听 passive: true；滚动回调用 rAF 节流
  • 倒排索引 + 中文 bigram 分词 + 120ms 防抖；结果一次性写入 DOM
  • 支持 prefers-reduced-motion 与打印样式；主题预置避免 FOUC

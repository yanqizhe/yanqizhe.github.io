关于本站

这是一份静态博客样品，用于演示「Hugo + Stack 风格静态站 + 零运行时前端」的形态。页面由纯 HTML / CSS / JavaScript 构成，不依赖任何框架、构建工具或外部 CDN，双击即可打开预览。

换成正式版本时，内容数据可直接映射为 Hugo 的 Markdown 与 Front Matter，托管到 Cloudflare Pages，评论与搜索分别交给 Waline 与 Pagefind。

页面中的作者、文章、声明均为占位内容；样品不冒充任何真实站点或个人。

关于原创与转载

文章按两类归档，判定标准从严：

仅当文章主要内容的绝大部分来源于撰稿者的独立思考、独创性表达、实操经验或一手调研时，才标记为「原创」。
  • 直接转载、仅由 LLM 翻译或排版、仅来自逆向工程的产物 → 标记为「转载」
  • 难以判断时，一律从宽标记为「转载」
  • 引用文段、翻译排版部分、读者不可见的程序代码，不计入「主要内容」
  • LLM 基于人类创意生成的内容若体现充分人工干预，可标原创，但须附明显 AI 标注

关于 AIGC

  • 主要内容中基于 GenAI 生成的图片或文本会明确标注
  • 目标：全站主要内容中 AIGC 占比保持低水平，且不再提高
  • LLM 的生成结果不保证正确性，必须由具备相关知识的人人工检查与事实核查
  • 文章主体由真人撰写；AI 参与的部分逐处说明
更多地假定它一定会犯错，会更有利于使用它。

关于评论

  • 为提供评论服务会收集 IP、User-Agent 等技术信息，但不会以任何方式公开
  • 不使用基于 Cookie 的评论功能，不向第三方提供信息（OAuth API 调用除外）
  • 使用 Akismet 自动过滤垃圾评论，必要时人工审核；审核仅防垃圾与网络攻击，不涉及观点过滤
  • 鼓励使用隐私保护邮箱注册评论身份，以便自行删除评论
  • 匿名昵称默认填充随机 UUID，便于区分不同发言者

样品站未启用评论服务，此处仅为政策文本示例。

Warrant Canary（透明度声明）

结构上，这类声明 = 一段带明确日期的静态文本 + 固定的更新节奏：声明截至某日期未收到特定类型的数据索取或内容审查请求，并承诺定期更新。

日期应手工写入内容而非自动生成，更新必须由站主主动完成；可选配 PGP 签名以证明发布者身份。

本样品不包含任何真实合规声明，此处仅演示该机制的页面结构。实际使用时须由站主本人核实并背书。

流畅度：本样品落实的性能实践

  • 零运行时框架：无虚拟 DOM、无水合；HTML 直出即所现
  • 系统字体栈：字体下载成本为 0；正式站可用 cn-font-split 做中文分片
  • content-visibility: auto + contain-intrinsic-size：屏外卡片跳过渲染且不跳滚动条
  • 固定宽高比封面：预留尺寸，CLS ≈ 0
  • 动画仅 transform / opacity：只走合成线程，不触发布局与重绘
  • 倒排索引 + 120ms 防抖：把搜索从 O(n) 全文扫描变成查表
  • 一次性 innerHTML、passive 滚动监听、rAF 节流、prefers-reduced-motion 支持

首次使用

  1. 在 GitHub 生成 Fine-grained token，只给本仓库 Contents: read/write 权限。
  2. 把令牌粘贴到上方，点击「连接 GitHub」。
  3. 连接成功后会拉取文章列表；点击「新建文章」即可写作。
  4. 保存后会提交到仓库，稍等片刻主站自动显示新文章。

不建议使用账号密码。令牌可设置过期时间，随时在 GitHub 撤销。
